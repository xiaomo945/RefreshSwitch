# 刷新率 · 分辨率 一键切换工具

> 一个通用、免安装、跨显示器的 Windows 刷新率 / 分辨率切换小工具。
>
> 起因很离谱：作者用了 10 年「144Hz」显示器，直到 2026.10.13 凌晨让 AI 帮忙，才发现这十年一直是 60Hz。

---

## ✨ 功能特性

- **实时检测，不写死任何参数**：启动时自动枚举当前显示器在所选分辨率下支持的全部刷新率，从 60Hz 办公屏到 1000Hz+ 电竞屏（卓威 600 / 蚂蚁电竞 750 / AUO 800 / LG·飞利浦 Evnia·三星 1000~1040）全部覆盖。
- **一键最高**：不知道选哪个？点一下「⚡ 一键最高」，自动切到你显示器支持的最高刷新率，不会黑屏。
- **常用档位全面覆盖**：`60 / 120 / 144 / 165 / 240 / 360 / 400 / 600 / 800 / 1000` Hz，一键即切。
- **超限自动回落**：点了一个你显示器不支持的档（比如 144Hz 屏点 800Hz），自动回落到本机该分辨率下的**最高档**，并明确提示原因。
- **分辨率 + 刷新率联动**：切换分辨率时若当前刷新率在新分辨率下不可用，同样自动适配。
- **彩色状态反馈**：切换后实时显示「您当前的显示器刷新率是 XXX Hz」，按档位颜色区分（满血绿 / 高刷蓝 / 标准橙）。
- **赞赏 & 点赞**：内置作者赞赏码与本地点赞计数。

## 🛠 使用

### 图形界面
双击 `RefreshSwitch.exe`：

1. 顶部金色大字显示「**本机最高刷新率**」，一眼就知道你显示器的上限。
2. 点「⚡ 一键最高」直达满血；或点常用档位 / 本机可用档位文字标签。
3. 想用特殊刷新率，在「自定义」框输入后点「应用」。
4. 底部有「作者的话」和赞赏入口。

> 不知道选哪个？直接点「一键最高」，工具会自动适配到你的显示器支持的最高刷新率。

### 命令行
```bash
refresh_switch.py list                # 列出全部分辨率及可用档位
refresh_switch.py 144                # 只改刷新率（保持当前分辨率）
refresh_switch.py 1920x1080          # 只改分辨率（刷新率自动适配）
refresh_switch.py 1920x1080@144      # 同时设定分辨率和刷新率
refresh_switch.py 144 DISPLAY2       # 指定第二台显示器
```

### 桌面快捷方式（可选）
```bash
python rebuild_shortcuts.py           # 在桌面生成「刷新率切换」快捷方式
```
默认只生成一个入口图标，不产生一堆热键图标，避免和其他软件快捷键冲突。

## 🔧 工作原理

工具**不假定任何显示器参数**。每次运行都用 Windows 显示 API（`EnumDisplaySettingsW` / `ChangeDisplaySettingsExW`）实时查询当前机器、当前分辨率下真实可用的「分辨率 × 刷新率」组合。

任何切换都先用 `CDS_TEST` 验证再正式应用，**切到不支持的模式不会黑屏**。回落目标 = 该机该分辨率下实测可用档位的最大值——所以别人用 600Hz 屏点 800 会回到 600，你用 144Hz 屏点 800 会回到 144，每个人各自计算。

## ❓ 常见问题

**Q：一直用 144Hz 会伤显示器吗？**
不会。刷新率只影响画面流畅度与显卡负载，真正影响寿命的是亮度、静态画面和散热。看 60fps 视频建议 120Hz（24fps 五倍频、无抖动）。

**Q：为什么我点了高刷档没变化？**
说明你当前分辨率不支持该档位，工具已回落到本机最高档并提示原因。

**Q：点完会黑屏吗？**
不会。每次切换都先 TEST 验证，系统拒绝的模式不会强行应用。

**Q：点赞计数是全网的吗？**
默认是**本机计数**（存在 `%APPDATA%\RefreshSwitch\likes.txt`），同一台机器只 +1 一次。想让全网用户累加同一个真实数字，按上方「☁️ 云端点赞计数」配置 Cloudflare Workers + KV 即可（免费、无需信用卡）。

## ☁️ 云端点赞计数（可选 · 免费）

默认点赞是**本机计数**。想让全网用户累加同一个真实数字，用 **Cloudflare Workers + KV** 即可（免费、无需信用卡）：

1. 在 Cloudflare 控制台创建一个 **KV 命名空间**，变量名(binding) 填 `LIKES`；
2. 把仓库里的 [`likes-worker.js`](likes-worker.js) 部署成 Worker（也可 `wrangler deploy`，配置见 [`wrangler.toml`](wrangler.toml)）；
3. 将 [`cloud_likes_url.example.txt`](cloud_likes_url.example.txt) 复制为 `cloud_likes_url.txt`，填入你的 Worker 地址（**结尾带 `/`**），放在 `RefreshSwitch.exe` 同目录。

启用后：启动时拉取全局总数，点「赞」会向云端 +1（**本机仍只 +1 一次**，不会重复计数）。Worker 代码只持有 KV 密钥，**exe 里只放公开 URL**，安全。
未配置时自动退化为纯本机计数，不影响使用。
